🎨 Streamlit App — Interactive Web Application

This repository contains my first hands-on Streamlit web application, built as part of my learning and my journey in Python + data tools.

Streamlit genuinely feels like low-code done right — you write Python, it gives you UI superpowers. 😄

🚀 Features

* Interactive UI powered by Streamlit
* Clean layout with titles, text, inputs, and more
* Runs locally on localhost:8501
* Beginner-friendly, easy to extend
* Minimal setup, deploy-ready
